# Contributing

Keep changes focused and include behavioral regression tests where useful. Preserve package identity, offline runtime, continuous motion, D-pad controls and the existing settings schema. Never commit signing keys or passwords.

Read [building](docs/building.md), [architecture](docs/architecture.md) and [verification](docs/verification.md). Run the complete local checks before opening a pull request. Rendering changes need moving native review; an unsigned CI build does not establish TV appearance or idle behavior.
