# Security

Report sensitive vulnerabilities through a [private security advisory](https://github.com/jeremykenedy/nibbles-hd/security/advisories/new). Include the affected version, reproduction and expected impact. Do not publish credentials or private device identifiers.

The current 1.0 release line receives fixes. The app runs offline; its exported settings provider deliberately allows local apps to read and update the documented scene options. It exposes no files, executable commands or system settings. Installer downloads happen on your computer, separately from app runtime.
