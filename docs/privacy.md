# Privacy

Nibbles HD runs offline. It contains no ads, analytics, tracking, telemetry, crash reporting, remote configuration, background update check or network client. It requests no Android permissions, including INTERNET. Its APK contains only project classes, Android resources and offline Apache/NOTICE assets, with no bundled native libraries or third-party SDKs.

The eight options stay in app-owned SharedPreferences. Android backup is disabled. The local settings provider intentionally lets local companion apps read and change those documented scene options; it does not expose files, private identifiers or system settings. Uninstalling removes local options.

Artifact checks inspect the final manifest, executable references, resources and notices. Native UID network baselines during review showed no app traffic. These checks support this version's offline boundary; they are not a claim about arbitrary modified builds. GitHub release downloads belong to the user-initiated computer installer or companion host, separately from saver runtime.
