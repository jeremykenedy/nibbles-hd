# Nibbles HD 1.0.0

An original autonomous snake screensaver with clean matte ribbons, real food/growth/collision rounds and varied routes. Runtime is offline, with no requested permissions, ads, tracking, analytics or background update checks.

## Upgrade guide

This is the first public release. Android 6.0/API 23 or later with DreamService support is required; target SDK is 36. Install the signed APK, or run `python3 install.py --serial YOUR_TV_IP:5555`. The guided installer verifies the latest release checksum and preserves selection/timers. Select Nibbles HD separately through a supported picker. Local same-signer code 1/2 candidates update in place to code 3 and retain all eight settings. Do not uninstall to work around a signature mismatch.

To roll back or remove, select your previous saver first, then run `python3 install.py --serial YOUR_TV_IP:5555 --uninstall`. Removal deletes Nibbles HD options; it does not alter other apps or system timers. There are no migrations, account credentials, services or caches to configure. [Installation guide](https://github.com/jeremykenedy/nibbles-hd/blob/v1.0.0/docs/installation.md).

## Breaking changes

None from an earlier public version; this is the initial release. The eight-key local candidate schema and defaults are preserved.

## Major changes

- Autonomous food-seeking gameplay with real growth, simultaneous collision handling and fresh rounds.
- Smooth native interpolation, matte materials, legible food and subtle whole-board movement, without scene words or watermark.
- Eight persistent, validated D-pad controls, per-option Random and optional randomize-all.
- Native Preview and proper DreamService lifecycle, with an app-owned settings provider.

## Minor changes and fixes

- Offline credits/Apache notices and an actual native-derived 384x216 preview.
- Guided standalone install/update/removal, restricted GitHub release downloads and SHA-256 verification.
- Responsive animated light/dark banners with still reduced-motion variants, native gallery and integration contract.

## Verification and limits

Gameplay/options and standalone installer host logic have 100% line/branch gates. CI checks style, docs/art and an unsigned APK's identity, SDK, Dream metadata, preview, notices and offline boundary. Production signing stays outside Git/CI.

The unchanged matte runtime was reviewed on physical Amazon AFTDEC012E API 30 at native 1920x1080, including ordinary five-minute idle binding, settings/Preview/Back, persistence and lifecycle. Actual default/high-load/normal-Dream movies were independently played to the end. Short SF samples ranged 53.62..60 presents/s while raw gfxinfo reported substantial jank; these mixed results do not establish universal 60 FPS. Background LOW_MEMORY reclamation was a recreation case, not an app crash. The exact signed code 3 same-signer update, retained eight-value schema, settled native Preview/Back, D-pad persistence, offline credits scrolling and app-provided thumbnail passed on the API 34 emulator with complete surrounding-state restoration. Native 4K, other physical devices, thermal endurance, reboot and hardware-remote testing remain unverified. [Detailed evidence and limits](https://github.com/jeremykenedy/nibbles-hd/blob/v1.0.0/docs/verification.md).
